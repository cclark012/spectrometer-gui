## SNR benchmark

The seeded benchmark uses 150 timed repetitions per size/method after warmup, broad PL peaks, a sloping offset and independent Gaussian noise. It compares the original manual-window estimator with block STD/MAD at 8 and 16 pixels. It also repeats noise estimation across 100 realizations for each block/method/slope combination.

| Samples | Automatic 16 pixel STD median | Automatic p95 | Manual windows median |
|---|---|---|---|
| 1024 | 0.211 ms | 0.358 ms | 0.706 ms |
| 2048 | 0.296 ms | 0.733 ms | 0.757 ms |
| 16384 | 1.442 ms | 2.394 ms | 2.809 ms |

For true noise sigma 5, the 16-pixel STD mean estimates were about 4.971 without slope and 4.977 with slope. MAD showed more small-block bias. An initial benchmark exposed a BLAS-backed norm slowdown at 16384 points; replacing it with a direct sum-of-squares reduction removed that overhead before integration. Initial and final JSON measurements are included. These are local synthetic results, not a throughput guarantee for the lab PC or evidence of unbiased SNR for all spectra.

## Target environment check

From the project root in the lab Python 3.14 environment, install/update the project and development dependencies with python -m pip install -e ".[dev]". SciPy is the new dependency for peak analysis. Then run python -m pytest -q and python verification/gui_smoke.py. The smoke test isolates QSettings and uses emulators only. It writes a result JSON and screenshots when successful.

The smoke test checks full-window construction, emulated connections, left-side scan selection, smoothed trace layering, an acquired spectrum through an asynchronous baseline/analysis operation and shutdown. Review the screenshots and manually check all eight lasers, scrolling at the lab display resolution, plot-style controls and settings persistence.
